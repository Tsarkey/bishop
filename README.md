# Bishop

🌌 Галерея изображений, наборы стикеров и тихая фоновая музыка  
в тёмно-фиолетовой эстетике - с лёгкой долей загадочности.  

🔗 Демо: [tsarkey.github.io/bishop](https://tsarkey.github.io/bishop/)

---

## 📂 Состав проекта
- **HTML / CSS / JS** - исходный код сайта (оформление, стили и логика).  
- **Музыка** - подключается через стриминг, файлы не входят в репозиторий.  
- **Изображения** - предоставлены автором-иллюстратором, права остаются у него.
